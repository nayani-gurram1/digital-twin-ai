## 💡 Project Overview

This project simulates a **Digital Twin of human behavior**.

It predicts what a user is likely to do next (study, sleep, scroll, exercise) based on real-time inputs like:
- Energy level
- Stress level
- Sleep
- Phone usage
- Workload

## 🧪 How It Works

1. Synthetic behavioral data is generated
2. Dataset is balanced to avoid bias
3. Machine Learning model (Random Forest) is trained
4. User inputs are taken via UI
5. Model predicts behavior
6. Recommendation engine suggests actions
